# Библиографический поиск по русской и английской литературе

Дата проверки 24.11.2026. Подборка ориентирована на первичные наблюдения и инженерное сравнение. Страница выдачи устанавливает лишь направление проверки; содержательные факты приводятся по фактически просмотренным документам.

## Маршруты и запросы

- Билингвальный поиск в Crossref и OpenAlex: «Карское море нефтегазоносность», «месторождения Карского моря геология», «Карское море шельф ресурсы», «Карское море техногенные угрозы», `Kara Sea reservoir`, `Kara Sea oil and gas fields seismic`, `Kara Sea shelf permafrost ice gouging`. Англоязычный поиск дал более точные попадания по геофизике и ледовым процессам, музейно-фаунистические результаты по общему географическому запросу исключались.
- Уточнения по DOI и выпуску, проверка выходных данных издателя и сопоставление страниц PDF. Результаты по смежным морям оставлены только для явных аналогий. Ссылки из списков литературы зарегистрированы ниже как кандидаты без приписывания им результатов.
- Доступные для чтения копии исследованы внутри проекта. Публикация включает библиографию, пересказ и адреса оригиналов. Полный PDF с неподтверждённым разрешением на повторное распространение остаётся локальной рабочей копией.

## Библиографические следы, требующие получения текста

Ссылки ниже восстановлены из списка литературы [S506, печ. с. 65 / PDF 5](../source_cards/S506.md). Они нужны для поиска в читальном зале и не засчитываются как изученные источники.

1. Сулейманов А. Б., Кулиев Р. П., Саркисов Э. И., Карапетов К. А. Эксплуатация морских нефтегазовых месторождений. М. Недра, 1988. 285 с. Базовая учебная и техническая терминология, потенциально полезна для исторического введения.
2. Кустышев А. В. Особенности эксплуатации шельфовых месторождений. Курс лекций. Тюмень. ТюмГНГУ, 2005. 118 с. Искомые разделы — различия конструкции морских скважин и эксплуатационных подходов.
3. Чумаков Д. С. Состояние и перспективы международного сотрудничества в Арктике // Нефтяное хозяйство. 2008. № 6. С. 51–53. Историческая постановка вопроса о кооперации.
4. Заикин А. П., Кемпф К. В., Набока Р. Р. Перспективы освоения месторождений Арктического шельфа РФ // Нефтяное хозяйство. 2015. № 11. С. 81–83. Срез концепций середины 2010-х.
5. Морозов А. Н. Морская ПБУ для акватории Тазовской и Обской губ // Газовая промышленность. 1998. № 6. С. 55–57. Территориально отдельный мелководный аналог.
6. Кириллов Н. Г., Лазарев А. Н., Ивановский С. В. Развитие инфраструктуры производства СПГ шельфовых месторождений — задача экономического и национальной безопасности России // Газовая промышленность. 2014. № 12. С. 42–46. Историческая инфраструктурная постановка, требует уточнения географии рассматриваемых проектов.

## Контроль числа

В этой части поиска пять отдельных полнотекстовых карточек и одна библиографическая. Шесть дополнительных следов выше относятся к поисковой перспективе и не входят в количество изученных материалов.
