# Месторождения шельфа Карского моря

Исследовательская база по дисциплине «Основы освоения морских нефтегазовых ресурсов». Журавлев Арсений Евгеньевич, РТ-23-12, вариант 7.

Цель — сопоставить геологию, ледовую обстановку, глубины, геотехнику и доступность инфраструктуры с инженерным выбором способов бурения, добычи и транспорта. База предназначена для будущего литературного обзора объёмом 30–50 страниц с рисунками и таблицами.
