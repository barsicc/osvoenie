# S506 — Освоение разведочных скважин в ледовых условиях

Кустышев Д. А., Кустышев А. В., Барков А. А., Антонов М. Д., Долгушин В. А. Освоение разведочных скважин в ледовых условиях Арктики // Известия высших учебных заведений. Нефть и газ. 2016. № 2. С. 61–66. DOI не подтверждён.

Первая страница PDF содержит начало статьи на печатной с. 61.

- **Печатная с. 62 / PDF 2.** Даны исторические значения плотности сейсморазведки — 0,21 км/км² по Карскому морю и 0,5 км/км² по Баренцеву и Печорскому морям. Первоначальную дату сводки и границы выборки нужно уточнять по источникам авторов. Значения пригодны для объяснения неравномерности исторической изученности, не как современные показатели.
- **Печатная с. 63 / PDF 3.** Обский-1 приводится как планируемое средство для Тюменского Севера с условной глубиной бурения 2500 м при глубине воды 2–10 м. Этот пример относится к мелководью, не определяет пригодность для открытого шельфа и не подтверждает фактическое выполнение конкретной операции.
- **Печатные с. 63–65 / PDF 3–5.** Авторы обсуждают специальную технологию испытания разведочной скважины в ограниченном ледовом окне и необходимость компенсировать перемещения обвязки при подвижках льда. Схема на с. 64 разделяет линию исследования и факельный отвод. Статья излагает предлагаемое решение, не отчёт об испытаниях и не проектную норму.
- **Печатные с. 62–63 / PDF 2–3.** В одной строке указано «Русановское», в соседнем абзаце — «Русаковское». Региональная география аналогов также изложена неоднородно: сначала названо Баренцево море для всей группы, далее Приразломное явно отнесено к Печорскому. Реестр месторождений сверять по профильным первичным источникам.
- **Использование.** Глава технологий, подраздел о сезонном опробовании. «Рисунок. Схема освоения разведочной скважины в ледовой обстановке» (печатная с. 64 / PDF 4) — историческая авторская концепция. В статье не показано внедрение предложенной схемы на перечисленных месторождениях.
