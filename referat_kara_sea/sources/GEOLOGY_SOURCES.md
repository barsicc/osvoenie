# Локальные копии по геологии

Карточки фиксируют URL и временную привязку изученных документов. Файлы S101, S107, S108 и S112 загружены с сайтов издателей для анализа и хранятся в локальной папке `sources/.local-geology/`. Копии в этой папке исключены из Git. Для независимой проверки откройте PDF по официальным ссылкам из карточек.
