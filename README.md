# osvoenie — ответы на тесты «Освоение морских нефтегазовых месторождений»

## Как быстро найти ответ
1. **Из терминала:**
   ```bash
   python3 poisk.py "глубина моря Приразломное"
   ```
   Без аргументов поиск работает в диалоговом режиме.
2. **Все проверенные ответы списком:** [`OTVETY.md`](OTVETY.md).

## Что где лежит
| Файл | Содержание |

**Добавить новый вопрос:** допиши его в `data/questions.json` и выполни `python3 poisk.py --build`.

### Выводы для следующих тестов
- **За неверный ответ снимают баллы** (−1), а в вопросах с несколькими ответами наказывают за лишние варианты. Отмечай только то, в чём уверен.
- Около половины вопросов касается **конкретных месторождений и платформ**: Приразломная, Штокман, «Сахалин-1/2/3», Карское море, Обско-Тазовская губа. На слайдах об этом мало, поэтому эти факты собраны в справочнике.
- **Печорское море ≠ Баренцево.** Приразломное и Долгинское относятся к Печорскому морю.
- **На карте photo_10 перепутаны глубины.** Штокмановское — 320–340 м, Приразломное — 19–20 м.
- В вопросах «Верно ли определение?» подменяют термин. «Часть геологических…» — это **извлекаемые** запасы; «в изученных бурением залежах» — **геологические запасы**; «в не вскрытых бурением» — **ресурсы**.
- Цифры, которые портал считает правильными, даже если в других источниках они другие: до Мурманска от Приразломного **1200 км**, Русановское — **газовое**.
